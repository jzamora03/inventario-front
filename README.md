
# 🎯 Proyecto de Gestión de inentarios

Este proyecto permite la gestión de inventarios, dejando agregar, editar y eliminar productos, así mismo agregar venta/compra de estos.

---

## 📌 1. Requisitos Previos  
Antes de comenzar, asegúrate de tener instalados:  
- [Angular14+](https://angular.dev/installation)
  
---

## ⚙️ 2. Instalación del Proyecto  
📌 **Clona el repositorio y accede a la carpeta:**  
```bash
git clone https://github.com/jzamora03/inventario-front
inventario-front
```
📌 **Instala las dependencias con npm**  
```bash
npm install
```

## ⚙️ 3. Iniciar el proyecto
📌 **Levantar el servidor del front con:**  
```bash
npm serve
```

📌 **El frontend esta corriendo en:**  
```bash
http://localhost:4200/
```

📌 **Para tener en cuenta:**  
- Verificar en los servicios el puerto en el que se esta levantando el backend por defecto esta el 5028.

## ⚙️ Solucion a posibles errores errores
📌 **Solucion**  
```bash
npm cache clean --force o reinstala con npm install
```
